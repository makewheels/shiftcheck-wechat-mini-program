## 原 README「版本更新日志」原文（该节 2026-09-14 已移除，原文保留在此）

- 开通广告，给每个页面加入 Banner 广告

## 后续更正（2026-09 复核）

- **「给每个页面添加转发按钮」实际未生效**：全仓库没有任何页面实现 `onShareAppMessage`，
  按微信规则右上角不会出现「转发」；20 处 `wx.showShareMenu()` 都是空操作，
  且都没传 `menus`，所以「分享到朋友圈」也不可用
- **强制更新有 3 处缺陷**（`onUpdateReady` 注册时机、无 `onUpdateFailed` 兜底、只挂首页 `onShow`
  导致非首页入口不检查），在 **2.4.0** 修复
- **ip138 查 IP 与静默读剪贴板**的采集在 **2.4.0** 移除；两个硬编码 token 已随公开仓库泄露，需作废
