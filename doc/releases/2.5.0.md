# 2.5.0

## 本版改动

- 完整移除 LeanCloud 使用统计与登录链路，不再向已失效的统计域名发送请求。
  删除两个不再使用的 SDK 文件，代码包从 260.9 KB 缩到约 25 KB。
  设备信息、网络状态和 openid 不再上报，断网行为与联网完全一致。
- 转发、分享到朋友圈真正可用：此前 11 个页面右上角都不会出现「转发」入口，
  本版统一接入（公共实现 `utils/share.js`），分享卡片直达当前页面并带页面标题。
- 月日历配色重做：普通日一律白底（上班红字、休息绿字），法定节假日浅红底红框红字，
  调休补班日橙色「班」角标，哪天放假一眼可见（两版方案截图对比后用户选定）。
- 「个人模式默认班组」对四种倒班全部生效：设置页按倒班分四行各自设置，
  各个人页打开时各自生效（此前只有五班三倒在用这个设置，其余三种固定默认一班）。
- 四班四倒、三班半倒的 4 个页面补上「跳转到指定日期」，与五班三倒、经警队一致。
- 11 个页面补充导航栏标题，从二级页返回时标题栏可区分所在页面。
- 首页单位名标签由 HTML `span` 改为小程序 `text` 组件，写法合规。
- 保留全部 8 个倒班页、月日历和设置功能，排班计算仍在本地完成。

## 验证与边界

- 自动化测试 169 项（2.4.0 为 135），新增转发接线与标题对应、默认班组读写契约、
  全页面沙箱加载与 wxml 禁 HTML 标签等门禁。
- 月日历配色经模拟器逐页截图核验（2026 年 10 月国庆 7 天假期与 10 日补班）；
  真机观感与「点某天回列表」手感仍需在体验版确认。
- 强制升级的端到端链路（上传新版 → 弹窗 → 重启）仍需等本版成为线上版本后验证。
- 上传开发版本后，由维护者在微信后台完成体验、提审与发布。
