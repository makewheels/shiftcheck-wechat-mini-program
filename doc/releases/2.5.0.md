# 2.5.0：移除失效的统计服务，启动不再等待登录

## 本版改动

- 完整移除 LeanCloud 使用统计与登录链路，不再向已失效的统计域名发送请求。
- 删除两个不再使用的 SDK 文件，缩减代码包。
- 首页保持倒班查询入口，不依赖登录或统计服务；设备信息、网络状态和 openid 不再上报。
- 保留全部 8 个倒班页、月日历和设置功能，排班计算仍在本地完成。
- 新增回归门禁，阻止统计 SDK、登录链路和相关调用被重新引入。

## 验证与边界

- 135 项自动化测试覆盖排班基准、日期计算、月日历、页面结构、首页行为和代码卫生。
- 本版只清理失效服务，月日历配色、组件替换与年度节假日数据更新继续留在待办。
- 真机离线使用、广告展示、强制升级完整链路仍需在体验版与线上版本中验证。
- 上传开发版本后，由维护者在微信后台完成体验、提审与发布。
