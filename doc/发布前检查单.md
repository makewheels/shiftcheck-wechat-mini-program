# 发布前检查单（2.4.0）

代码改不动的部分都在这里（后台配置、凭据处置、上传提审）。带 ⚠️ 的是不做就会被驳回或线上直接不可用的。

## 1. ⚠️ 服务器域名白名单

小程序后台 → 开发管理 → 开发设置 → 服务器域名 → **request 合法域名**：

- `https://api.leancloud.mp.shiftcheck.work`

全仓库现在只有这一个网络域名（原来查 IP 用的 `api.ip138.com` 已随采集一起移除），
`downloadFile` / `uploadFile` / `socket` 域名都不需要配。

注意：`project.private.config.json` 里的 `urlCheck: false` 只在开发者工具里生效，
**线上照样要配白名单**，否则请求全部失败、页面一直转圈。

## 2. ⚠️ 用户隐私保护指引

小程序后台 → 设置 → 服务内容声明 → 用户隐私保护指引。按现在的代码，需要声明这些：

| 信息类型 | 用途 | 代码位置 |
| --- | --- | --- |
| 剪贴板 | 用户点「一键粘贴」时读取规则激活码 | `pages/setting/importRuleByKey/importRuleByKey.js` |
| 邮箱 | 上班提醒推送（用户自己在「我的账户」里填） | `pages/setting/updateMail/` |
| 手机号 | 上班提醒短信推送（用户自己填） | `pages/setting/updatePhone/` |
| 设备信息、网络状态 | 使用统计（机型 / 系统 / 窗口尺寸 / 网络类型 / 屏幕亮度） | `pages/index/index.js` 的 `mystep2()` |
| 微信 openid | 标识用户，关联其规则与推送设置 | LeanCloud 小程序登录，全局 |

基础库 2.32.3 起，未声明就调用隐私接口会被直接拦截（`getClipboardData` 会 fail）。
不想声明剪贴板的替代做法：去掉「一键粘贴」按钮，让用户自己长按输入框粘贴。

已经**不再收集**的：剪贴板内容的后台静默上报、IP 归属地（这两项本次已移除）。
