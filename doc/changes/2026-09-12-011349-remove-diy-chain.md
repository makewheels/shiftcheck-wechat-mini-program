# 2026-09-12 01:13 删除整条 DIY 自定义规则链路（4 个页面）

## 背景/目的

DIY 规则链路的**导入侧对新用户 100% 不可用**，而界面上看不出来：

1. **没有任何代码能创建 `Rule` 或 `RuleKey`**：全仓库只有读取与更新
   （`Rule` 读于 `diy.js` / `myRuleHome.js` / `newPushMission.js`，`RuleKey` 读于 `importRuleByKey.js`），
   零处 `new (AV.Object.extend('Rule'))` 或 `new (AV.Object.extend('RuleKey'))`。
   也没有任何后台页 / 管理端 / 脚本。原本承担这个职责的 `shiftcheck-server` 已停用
   （`doc/README.md`）。所以激活码只能靠人工去 LeanCloud 控制台建行
2. **用户侧表现**：点「激活码导入」→ 扫码或粘贴 → 查 `RuleKey` → 0 行 → 弹「激活码错误！」。
   而**全仓库没有任何地方告诉他去哪弄码**（反馈页此前已删，入口按钮本来就是注释的）
3. **导入页还有一个不可逆的坑**：`importRuleByKey.js` 裸取 `app.getOpenid()`，
   登录未回来时是 `null`，此时激活码照样被置为已使用、规则挂到 `openid=null` 上，
   而界面弹「激活成功！」—— 用户的一次性激活码被烧毁且拿不回来
4. **`diyPush` 页的推送次数**依赖上一 PR 删掉的推送链路，已无意义

存量用户（数据库里已有 `UserRule` + `Rule` 行）的 `pages/diy/diy` 查班本来还能用，
但既然导入侧已经死了、没有新增用户能进来，保留它只是留一个半死不活的入口。
**核心查班功能（4 种倒班方式 × 个人/总览 = 8 个页面）是纯本地计算，与 DIY 完全无关。**
