# 2026-09-11 全部倒班页新增「月日历」视图（含法定节假日标注）

## 背景/目的

倒班页（个人 / 总览）原来只有一周 7 行列表，往前往后翻一周看不到整月形态，也看不出法定假期。
本次给**全部 9 个倒班页**加上月日历视图，与一周列表可切换，日历上标出法定节假日与调休补班日。

## 改动清单

**新增公共实现**

- `utils/calendar.js`：`buildMonth()` 构建整月渲染数据（周一起始、前后补空格、今天标记、节假日标注）；
  `refresh()` / `toggleView()` / `changeMonth()` / `dayTap()`；
  `onDate()` —— 临时把页面日期换成指定某天再还原，用来**原样复用页面里已有的班次算法**，不另写第二套
- `utils/holiday.js`：内置法定节假日与调休补班日数据 + 查询方法
- `components/shift-calendar/`：自定义组件（4 个文件），负责渲染日历网格；组件样式隔离，不受 `app.wxss` 影响

**9 个倒班页**（wbsd / sbsd / sbbd / jjd 的 worker 与 director，以及 diy）

- `data` 增加 `viewMode`（`list` / `calendar`）与 `cal`（日历渲染数据）
- 新增 `getDayCell(year, month, day)`：返回该天格子文字与「是否上班」
- 新增 4 个一行转发方法：`toggleView` / `backMonth` / `nextMonth` / `onCalendarDayTap`
- `setText()` 末尾调用 `calendar.refresh(this)`（列表模式下直接返回，无额外开销）
- 4 个总览页与 diy 页：把 `getRow()` 拆成 `getRow()`（日期前缀 + 内容）与 `getDayText()`（只有内容），
  日历格子复用 `getDayText()`
- `.wxml`：加「切换成月日历 / 切回一周列表」按钮；7 行列表包进 `wx:if`，另加 `<shift-calendar>`；
  日历模式下「前一天/后一天、上一周/下一周」换成「上一月/下一月」
- `.json`：注册 `shift-calendar` 组件
- `app.wxss`：新增 `.container.calendar-mode`，日历模式下收窄顶部留白、高度交给内容以便滚动

**节假日数据来源（都按官方通知原文逐条核对）**

- 2025 年：《国务院办公厅关于2025年部分节假日安排的通知》（国办发明电〔2024〕12号）
  <https://www.gov.cn/zhengce/content/202411/content_6986382.htm>
- 2026 年：《国务院办公厅关于2026年部分节假日安排的通知》（国办发明电〔2025〕7号）
  <https://www.gov.cn/zhengce/content/202511/content_7047090.htm>
- **2027 年通知尚未发布，因此没有内置 2027 年数据**（不推测、不编造）。
  没有数据的年份，日历会显示「该年节假日数据尚未内置」，只标班况

## 验证方式

Node 机器验证（本机开发者工具 CLI 服务端口未开启，命令行编译/上传用不了，界面级验证待补）：

1. **日历格子 vs 列表真值**：列表模式走的是原有代码路径（已由上一个 PR 的回归确认与改动前完全一致），
   把它当真值，逐格比对日历渲染结果 —— 9 个页面 × 全部班组 × 4 个月份（2026-09 含中秋国庆、
   2026-02 春节、2025-10、2024-02 无数据年）
2. **节假日数据自检**：逐日扫描 2025、2026 两年，断言放假日 28 / 33 天、补班日 5 / 6 天与通知一致；
   补班日必须落在周末；`dateKey` 能反解回同一天；官方通知里的 20 个具体日期抽查
3. **网格几何**：每行 7 格、格子总数等于当月天数、2026-09 首格为空（9/1 是周二、周一起始）、5 行
4. **交互**：1 月 31 日点「下一月」收敛到 2 月 28 日（不溢出到 3 月）；点日历某天回到列表且以该天开头；
   空 `detail` 不改变状态
5. **回归**：与上一个 PR 逐日比对 7 行输出，9 个页面全部 0 处不一致（本 PR 不改任何班次算法）
6. `node --check` 全部 js、`JSON.parse` 全部 json 通过

合计 **8179 项断言通过**（日历相关）+ **2391 项**（周期性不变量）+ 回归 0 差异。
