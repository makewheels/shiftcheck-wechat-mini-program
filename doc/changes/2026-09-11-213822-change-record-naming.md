# 2026-09-11 21:38 变更记录文件名加上时分秒

## 背景/目的

原规范是 `YYYY-MM-DD-简短说明.md`。实际一天里会有多次提交（2026-09-11 一天就有 12 次变更），
只写日期既看不出先后顺序，同主题的改动还容易撞名。按要求把命名规范改成带时分秒。

## 改动清单

- `doc/README.md`「变更记录」小节：命名规范 `YYYY-MM-DD-简短说明.md` → **`YYYY-MM-DD-HHMMSS-简短说明.md`**
  （24 小时制，取提交时的本地时间），并写明为什么必须带时分秒
- 本文件即第一条按新规范命名的记录

## 未做的事（说明理由）

- 本次**没有**追溯重命名当时已有的 12 份记录，理由是：它们的名字被 12 个已合并 PR 的正文、
  `doc/TODO.md`、`doc/README.md` 与彼此之间大量互相引用，改名会让这些历史 PR 里的链接失效。
  **后续已按要求补做了追溯重命名**（见 `doc/changes/2026-09-11-231054-changes-rename-hhmmss.md`），
  代价就是那些历史 PR 正文里的链接指向旧文件名、需要靠 git 历史查；
  仓库内的引用已全量更新，并由 `test/hygiene.test.js` 的文件名格式检查兜住
