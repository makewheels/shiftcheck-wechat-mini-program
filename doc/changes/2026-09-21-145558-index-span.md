# 2026-09-21 14:55 首页单位名标签：HTML 的 <span> 统一成 <text>

## 背景 / 目的

`doc/TODO.md` 第 6 节记的遗留：`pages/index/index.wxml` 有 2 处单位名标签
（「中 油 电 能」「采 油 队」）用的是 HTML 的 `<span>`，同页其它分组标签都是 `<text>`。
wxml 并不认识 `<span>`，开发者工具会告警，真机上属于「碰巧能渲染」。

## 改动清单

- `pages/index/index.wxml`：2 处 `<span>` → `<text class="unit-label">`
- `pages/index/index.wxss`：`span {}` 选择器 → `.unit-label {}`，
  字号（50rpx）/颜色（blue）/右边距（210rpx）/上下边距保持原值；
  转成 `<text>` 后会吃到本页 `text` 通用规则（`padding-top: 8rpx; line-height: 100rpx`），
  与同页分组标签（「五班三倒：」等）表现完全一致
- `test/structure.test.js` 新增门禁：wxml 里不许出现常见 HTML 标签
  （span/div/p/a/h1~h3/ul/li/table），防止再混进来
- `doc/TODO.md` 勾掉对应条目

## 验证方式

- `node --test test/*.test.js` 全绿（新增 1 条，共 153）
- 全仓库 grep 无 `<span>` 残留
- **界面层未验**：标签行高因吃到 text 通用规则会与分组标签行一致（原来略矮），
  属预期中的对齐改善，仍需模拟器/真机过一眼
