# 2026-09-11 修复锚点日之前的日期算错班（9 个倒班页统一修）

## 背景/目的

各倒班页算班次都是「与排班基准日（锚点）相差多少天，再对循环长度取模」。原来的写法：

```js
var days = parseInt(Math.abs(date2 - date1) / 1000 / 60 / 60 / 24)
...
var remainder = total % 5
```

`Math.abs()` 把天数差变成了绝对值，于是**锚点日之前的日期被当成正数取模，班次会算反**。
例如经警队锚点是 2026-09-10（一班上班），按规则 09-09 应该是四班，但 `abs(-1) % 4 = 1` 会算成二班。

- 老页面（wbsd / sbsd / sbbd）锚点在 2016、2017 年，用户基本翻不到那么早，所以一直没暴露；
  但「跳转到指定日期」的 picker 是允许选到锚点之前的，选了就错。
- 经警队锚点是 2026-09-10（就是上线前一天），用户往前翻一天就错，属于必须修的问题。

## 改动清单

- 新增 `utils/shift.js`：`mod(n, m)`（负数也落在 `[0, m)`）、`daysBetween(d1, d2)`（有符号）、
  `dateKey` / `weekName` / `daysInMonth`
- 9 个倒班页（wbsd / sbsd / sbbd / jjd 的 worker 与 director，以及 diy）：
  - `getTotalDays()`：`parseInt(Math.abs(date2 - date1) / …)` → `shift.daysBetween(date1, date2)`，保留各自锚点日期不变
  - 所有 `total % N` → `shift.mod(total, N)`；diy 的 `getTotalDays() % periodList.length` 同样处理
- 未改动任何锚点日期、班组循环表（`loopBody`）与页面交互

## 验证方式

1. **回归（最重要的那条）**：用 Node 加载改动前后的两版页面，对 9 个页面 × 全部班组 × 锚点前 40 天到后 1500 天逐日比对 7 行输出：
   - **锚点日及之后：36020 个样本，0 处不一致** —— 已校准的班次一个都没变
   - 锚点之前：按预期发生变化（这正是要修的 bug）
2. **周期性不变量**：倒班是纯周期循环，任意日期 d 都应满足 `班次(d) === 班次(d + N)`（N 为该页循环长度：5 / 4 / 21 / 4 / periodList.length）。
   对 9 个页面 × 全部班组 × 锚点前后各 60 天断言，**2391 项全部通过**。
   同一测试在改动前的代码上**会失败**（例如 `偏移 -1 与 4 应同班：「休息」vs「后夜(零点)」`），说明它确实能检出这个 bug，不是空转。
3. **经警队班表逐日核对**：09-06 一班、09-07 二班、09-08 三班、09-09 四班、09-10 一班、09-11 二班；
   跨月跨年：2026-08-30 二班、2026-01-01 一班、2025-01-01 四班。总览页与个人页一致。
4. `node --check` 全部 js 通过。
