# 2026-09-14 14:01 2.4.0 上传为开发版本；同步已被实测推翻的文档说法

## 背景 / 目的

2.4.0 的代码侧准备在 `2026-09-14-121358-release-240-prep.md` 那一轮已经完成，本次是把它真的传上去，
以及把两处**已经被今天实测推翻**的文档说法纠正过来。

上传过程中撞到两个报错，都把排查方向指错了，值得记下来：

1. `UNABLE_TO_GET_ISSUER_CERT_LOCALLY` —— 工具的 Node 侧不信任出网路径上重签的证书链
2. 「登录用户不是小程序开发者」—— **这是 1 的下游伪装，不是真的权限问题**

第 2 条的指纹是进度条打出 `Fetching AppID () permissions`，**括号是空的**：
读 appid 依赖 `requestProjectAttr`，而那一步被 1 打掉了，于是工具拿着空 appid 去问权限，
服务器只能回答"不是开发者"。第 1 条修好后，同一台机器、同一个微信账号、同一份代码，
输出立刻变成 `✔ Using AppID: wx46b9f529e9244893` → `✔ upload`。

**如果照着报错文案去后台查成员权限，会一路查错方向。**
